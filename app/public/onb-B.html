The psychology, pinned to the pixel

1

Goal-Gradient

The bar is born at 15% and only ever climbs — Back never drains it. The final stretch lands together with the import payoff, so completion and reward arrive as one moment.

2

Smart Defaults → real data

v1 guessed four common courses. Now the connection returns the student's actual roster, so the screen opens already correct — the strongest default is the true one. Editing stays one tap away.

3

IKEA / Endowment

You build first, commit last, and in this version the commitment is the connection. Schoology already knows who the student is, so there is no account to invent and no form at the end. The flow ends on the payoff, not on a wall.

4

Friction killer — deleted, not decorated

v1 spent five animated slides teaching students to hunt down a calendar link. The integration removes the step instead of explaining it: one tap, no URL, nothing to copy. The best fix for a hard step is not a better tutorial.

5

No side door

Skip is gone. A student who skips forgets, opens an empty app, and concludes the product is bad — the connection is the product, so the flow offers no way past it.

6

Reciprocity — the payoff

The flow ends by giving: every imported assignment, not a teaser. The count in the headline and the rows below it are the same data, so the number is never a claim the list contradicts.

7

Ask once you have earned it

The name is requested after the connection pays off, not before. Schoology already supplied one, so the field arrives pre-filled and the ask is a confirmation rather than a form.

S

Settings mirror

The Courses screen is the Settings ▸ Courses UI, verbatim — color dot, editable bold name, ✕. What you set up here is exactly what you’ll edit there later.

–

Anchoring — absent

No price exists in onboarding, so nothing to anchor. Reserved for the premium screen.

–

Sample — on the landing page

Give-before-ask already happened: the landing page’s playable demo is the free taste. Onboarding starts after reciprocity has done its job once.
