Which layer is making the noise

Everything measurable inside Cobalt is clean: the dirt leaving the limiter sits at the chain's floor. But no measurement from inside the page can see what happens after the sound card, which is where a remote-desktop session lives. This settles it by ear, because that is the only instrument on the far side.

1. Plain element, no Web Audio at all

2. Web Audio, bare

The same file through an AudioContext with a single gain node at 1.0. This is the minimum Web Audio path: if step 1 is clean and this is not, the fault is Web Audio meeting your audio device, not anything Cobalt does with it.

3. The real Cobalt engine

Full graph: normalization gain, warmth shelf, limiter, fade-in, watchdog.

4. Cobalt with the fade and the watchdog switched off

What you asked for: the two things added this week, removed. Same graph otherwise.

5. Cobalt stripped to a bare gain

Warmth shelf and limiter bypassed too, so only the volume gain remains. If 3 is dirty and this is clean, the fault is in one of those two nodes.
