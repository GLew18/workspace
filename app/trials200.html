200 live translation trials

Every sentence is real: produced by a translator from a known English seed, so each trial has an objective expected meaning. Each one runs through Cobalt's actual pipeline, which calls Google Cloud Translation through the deployed translateTitles function — so this exercises the shipped path end to end, not a stand-in. You must be signed in, because the function requires it.
